# Music Player

A simple web-based music player built with HTML, CSS, and JavaScript. It provides a clean interface for playing songs, controlling volume, navigating the playlist, and tracking playback progress.

## Features
- Play and pause music
- Go to the next or previous track
- Seek through the current song using the progress bar
- Adjust volume
- Click songs from the playlist to play them
- Auto-play the next track when one finishes

## Project Structure
- index.html - Main structure of the music player UI
- assets/css/style.css - Styling for the player
- assets/js/script.js - Music playback logic and playlist behavior

## How to Use
1. Clone or download this repository.
2. Place your MP3 files in a folder named songs/ inside the project root.
3. Update the song list in assets/js/script.js with your file names and metadata.
4. Open index.html in your browser to start listening.

## Notes
- This project does not require any installation or build step.
- It works best in a modern browser such as Chrome, Edge, or Firefox.
